# SFAT staging bootstrap

Bootstrap temporaire pour installer la distribution officielle PrestaShop
8.2.8 sur `dev.sfat-industrie.fr`.

Le script télécharge exclusivement l'archive de la publication officielle,
vérifie son empreinte SHA-256, puis l'extrait dans le dossier courant.

Aucune donnée, aucun identifiant et aucun thème commercial ne sont inclus dans
ce dépôt.
